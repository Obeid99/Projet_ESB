# ESB Admin Chatbot Frontend — High-Level Documentation

## Overview

The frontend of the ESB Admin Chatbot is a modern web application built with Next.js and React. It provides administrators with an interactive interface to view, analyze, and manage student feedback data. The UI is designed for clarity, responsiveness, and ease of use, supporting features such as authentication, dashboard analytics, chatbot interaction, and feedback visualization.

---

## Main Structure

- **Framework:** Next.js (React-based, server-side rendering and routing)
- **Styling:** CSS modules and global styles (e.g., `App.css`, `ChatbotPage.css`)
- **Component Library:** Chakra UI (customized via `lib/chakra.tsx`)
- **State Management:** React context/providers (see `AppWrappers.tsx`, `providers.tsx`)
- **Routing:** File-based routing under `app/` (Next.js convention)

---

## Key Folders & Files

- `app/`
  - **`layout.tsx`**: Main layout wrapper for all pages (navigation, theming, etc.)
  - **`page.tsx`**: Home or landing page
  - **`login/`, `register/`, `welcome/`**: Authentication and onboarding flows
  - **`administration-dashboard/`, `administration-chatbot/`, `administration-login/`**: Admin-specific dashboards and tools
  - **`chatbot/`**: Chatbot interface for admin queries and analytics
  - **`public/static/`**: Chart images and static assets for feedback visualization

- `src/components/`
  - **UI Components:** Modular React components for UI (e.g., `MessageBox`, `MarkdownBlock`, `CodeBlock`, `card/`, `fields/`, `header/`, `footer/`, `sidebar/`, etc.)
  - **Reusable Elements:** Icons, images, links, navbar, search, separator, etc.

- `src/styles/`
  - **Global and Page Styles:** CSS files for overall look and feel

- `src/theme/`
  - **Custom Theme:** Chakra UI theme overrides and additions

- `src/utils/`
  - **Helpers:** Chat streaming, navigation, and utility functions

---

## Main Features

- **Authentication:** Secure login/register for admins and users
- **Dashboard:** Visual analytics (charts, stats) for feedback data
- **Chatbot Interface:** Natural language admin queries, real-time analytics, and feedback exploration
- **Navigation:** Sidebar, navbar, and responsive layout for easy access to all features
- **Theming:** Consistent, modern look with Chakra UI and custom styles

---

## Data Flow & Integration

- **API Communication:** Frontend communicates with the backend Flask API for authentication, feedback data, and analytics
- **Chart Rendering:** Static chart images are generated by the backend and displayed in the UI (from `public/static/`)
- **Session Management:** Uses cookies or local storage for authentication/session state

---

## Extensibility

- **Component-Based:** Easy to add new UI features or analytics panels by creating new components/pages
- **Theming:** Customizable via Chakra UI and CSS modules
- **Routing:** Add new pages by creating new files/folders under `app/`
